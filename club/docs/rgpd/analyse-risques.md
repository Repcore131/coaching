# Analyse de risques (une page) : Fit Pulse

| Risque | Gravité | Mesures en place | Risque résiduel |
|---|---|---|---|
| Accès d'une personne extérieure à la base | Élevée | Compte personnel, code révocable, règles d'accès par rôle, archivage qui révoque la clé | Faible |
| Membre qui consulte ou modifie au-delà de son rôle | Moyenne | Écritures limitées par collection et par rôle ; audit en création seule | Faible |
| Divulgation d'impayés (réputation de l'adhérent) | Élevée | Pas de nom de client dans les notifications ; exports tracés et marqués CONFIDENTIEL ; effacement sur demande | Faible |
| Conservation excessive | Moyenne | Durées définies, purge outillée, année de naissance supprimée | Faible |
| Fuite par un appareil perdu | Moyenne | Copie locale effacée à la déconnexion ; code révocable par le manager | Modéré |
| Données sensibles saisies en texte libre (notes, chat) | Moyenne | Avertissement sous le bouton d'image ; notes limitées en longueur | Modéré |
| Messages non sollicités (SMS, WhatsApp) | Moyenne | Opposition par client, heures calmes, mention STOP sur les messages marketing | Faible |

**Conclusion.** Le traitement ne fait ni profilage à effet juridique, ni traitement de données sensibles, ni surveillance systématique à grande échelle. Une AIPD complète ne paraît pas obligatoire ; à réexaminer si le traitement s'étend à plusieurs sociétés ou ajoute un envoi automatique massif de messages.
