# Preuve d'antériorité : enveloppe e-Soleau (INPI)

L'enveloppe e-Soleau date de façon certaine la création de Fit Pulse et identifie ses auteurs. Elle sert de preuve en cas de copie.

1. Créer un compte sur https://procedures.inpi.fr (au nom de Kévin GUELLEC ; ajouter FPN GESTION comme co-déposant).
2. Choisir « e-Soleau », déposer le paquet préparé : `FitPulse-depot-anteriorite-AAAA-MM-JJ.zip` (code source complet, documents légaux, captures d'écran).
3. Payer la redevance (15 € pour une enveloppe), conserver l'accusé de dépôt avec la convention de copropriété.
4. Refaire un dépôt à chaque grande version (environ une fois par an).

Le paquet se régénère avec : `node club/outils/paquet-anteriorite.mjs` (fichier créé dans `club/_dist/`).
