# Relève des résiliations sur Microsoft 365 (Outlook)

Pour un club dont la boîte accueil est sur Microsoft 365, la fonction `graphPoll` (club/cloud, toutes les heures, fuseau Europe/Paris) lit la boîte avec Microsoft Graph, applique le même moteur de détection que le script Gmail (`moteur-mail.js`) et range les demandes dans Résiliations. Aucun mot de passe de boîte n'est demandé ni stocké.

## 1. Enregistrer l'application dans Entra ID

1. Centre d'administration Microsoft Entra, Applications, Inscriptions d'applications, Nouvelle inscription. Nom : « Fit Pulse relève ». Comptes de cet annuaire uniquement. Pas d'URI de redirection.
2. Notez l'**ID d'application (client)** et l'**ID de l'annuaire (locataire)**.
3. Certificats et secrets, Nouveau secret client (24 mois). Copiez la **valeur** tout de suite : elle n'est plus affichée ensuite.
4. Autorisations des API, Ajouter une autorisation, Microsoft Graph, **Autorisations d'application**, `Mail.Read`. Rien d'autre.
5. Cliquez sur **Accorder un consentement d'administrateur** pour l'organisation.

## 2. Limiter l'accès à la seule boîte accueil

Sans cette étape, `Mail.Read` en autorisation d'application ouvre toutes les boîtes de l'organisation.

1. Créez un groupe de sécurité à extension messagerie (par exemple `fitpulse-releve@votreclub.fr`) et ajoutez-y **uniquement** la boîte accueil.
2. Dans Exchange Online PowerShell :

       Connect-ExchangeOnline
       New-ApplicationAccessPolicy -AppId <ID d'application> -PolicyScopeGroupId fitpulse-releve@votreclub.fr -AccessRight RestrictAccess -Description "Fit Pulse : boîte accueil seulement"
       Test-ApplicationAccessPolicy -AppId <ID d'application> -Identity accueil@votreclub.fr        # AccessCheckResult : Granted
       Test-ApplicationAccessPolicy -AppId <ID d'application> -Identity direction@votreclub.fr      # AccessCheckResult : Denied

La stratégie peut mettre jusqu'à une heure à s'appliquer.

## 3. Ranger les secrets dans Secret Manager

    firebase functions:secrets:set M365_TENANT_ID
    firebase functions:secrets:set M365_CLIENT_ID
    firebase functions:secrets:set M365_CLIENT_SECRET

Ils ne sont écrits ni dans la base ni dans le code. Renouvelez le secret client avant son expiration (Entra ID affiche la date).

## 4. Régler le club dans Fit Pulse

Réglages, Relève des résiliations : Messagerie de l'accueil = Microsoft 365, Boîte Microsoft 365 = l'adresse de l'accueil, puis Enregistrer les règles. Le champ `mailProvider` du club passe à `m365`.

## 5. Déployer et vérifier

    cd club/cloud && npm install && npm run copier && npm run build && firebase deploy --only functions:graphPoll

Après le passage suivant, la page Résiliations affiche « Dernière relève : il y a N min ».

## Ce que fait la fonction

- Recherche `"resiliation OR résiliation OR résilier"` dans la boîte, garde les 45 derniers jours (Graph ne combine pas `$search` et `$filter` sur les messages : la date est filtrée après la recherche).
- Relit chaque conversation (`conversationId`), Éléments envoyés compris : une réponse de l'accueil fait passer la demande en phase « en cours ».
- `threadId` = `conversationId`, lien = `webLink` du premier message.
- Journal : identifiant du club, nombre de fils, durée. Ni nom, ni e-mail, ni téléphone.
